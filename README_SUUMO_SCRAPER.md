# SUUMO物件スクレイピングツール

## 概要
SUUMOの物件一覧ページからデータを抽出し、Excelファイルに出力するツールです。

## ファイル構成
- `parse_suumo_html.py` - 保存済みHTMLを解析してExcelに出力
- `create_sample_excel.py` - サンプルデータでExcelを作成
- `suumo_properties.xlsx` - 出力されたExcelファイル

## 使い方

### 方法1: ブラウザで手動でHTMLを保存

1. **ブラウザでSUUMOページを開く**
   ```
   https://suumo.jp/jj/bukken/ichiran/JJ012FC001/?ar=060&bs=011&cn=20&cnb=10&et=5&fw2=&jc=042&kb=1&kt=7500&mb=50&md=2&md=3&mh=151&mt=70&sc=27103&sc=27106&sc=27109&sc=27111&sc=27127&sc=27128&ta=27&tj=0&bknlistmodeflg=1&pc=30&page=1
   ```

2. **HTMLソースを保存**
   - Windows/Linux: `Ctrl + U` でソース表示 → `Ctrl + A` で全選択 → `Ctrl + C` でコピー
   - Mac: `Cmd + Option + U` でソース表示 → `Cmd + A` で全選択 → `Cmd + C` でコピー
   - または `Ctrl + S`（`Cmd + S`）で「Webページ、HTMLのみ」として保存

3. **テキストファイルとして保存**
   - メモ帳などに貼り付けて `suumo.html` として保存

4. **スクリプトを実行**
   ```bash
   python parse_suumo_html.py suumo.html
   ```

### 方法2: 開発者ツールからHTMLを取得

1. ブラウザでSUUMOページを開く
2. `F12` で開発者ツールを開く
3. Elementsタブで `<html>` を右クリック
4. 「Copy」→「Copy outerHTML」を選択
5. テキストファイルに貼り付けて保存

## 出力Excelの項目

| 項目 | 説明 |
|------|------|
| 物件名 | マンション名 |
| 価格 | 販売価格（万円） |
| 所在地 | 住所 |

| 間取り | 2LDK, 3LDKなど |

| バルコニー | バルコニー面積 |

## 検索条件（この例の場合）
- エリア: 大阪府大阪市（北区・中央区・西区・天王寺区・福島区・浪速区）
- 価格: 1万円〜7,500万円
- 専有面積: 50m²以上
- 駅徒歩: 5分以内
- 間取り: 2LDK・3LDK

## トラブルシューティング

### 「物件情報を抽出できませんでした」と表示される場合
- HTMLファイルが正しく保存されているか確認
- 文字エンコーディングがUTF-8になっているか確認
- SUUMOのページ構造が変更された可能性があります

### 一部の項目が空欄になる場合
- SUUMOのHTML構造はページによって異なる場合があります
- 必要に応じて `parse_suumo_html.py` のセレクタを調整してください
